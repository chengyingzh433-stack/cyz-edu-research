# CYZ 教育研究工作流 0.3.0

这套工作流帮助你在 Codex 中开展教育研究：找选题、读文献、整理证据、设计研究、分析材料，再据此写作和审查论文。你可以从零开始，也可以带着一个教学困惑、几篇 PDF 或已有草稿接着做。

它以 Skill 的形式安装到 Codex。安装后直接用中文描述当前情况即可。这个版本不包含独立桌面软件；三栏研究工作台仍在开发。

## 能帮你做什么

| 你现在的情况 | 工作流怎样推进 | 会留下什么 |
| --- | --- | --- |
| 想做教育研究，还没有选题 | 先了解学科、学段和资料条件，扫描相关文献，比较可做的方向 | 检索记录、方向比较、代表文献、下一步建议 |
| 已有教学困惑或初步想法 | 从现有想法出发，追问关键条件，查找相近研究，检查反例和替代解释 | 逐步更新的选题卡、问题修订记录、研究简报 |
| 手头有一批论文 | 按需要快速扫描或精读，记录方法、发现、局限及来源位置 | 文献卡、证据矩阵、待核验清单 |
| 想读取 PDF 中的内容 | 先检查已有转换缓存；需要时调用本地 MinerU Desk，或明确采用原生提取回退 | Markdown 阅读缓存、原文页码或块定位、图片及解析风险记录 |
| 准备做研究设计或分析 | 核对研究问题与方法是否匹配，说明样本、工具、伦理和数据要求 | 研究设计、分析计划和需要补齐的材料 |
| 已有结果或论文草稿 | 按已有证据起草、修改，检查引文、数字、结论范围和缺失信息 | Markdown 稿件、审查报告、待处理事项 |
| 想把学术文字改得自然 | 中文调用 humanizer-zh，英文调用 humanizer；保留改写前文本，再检查数字、引用和结论是否改变 | 修改稿、语义检查与人工复核记录；依赖安装要求见下文 |
| 中断后想继续 | 读取项目状态，找到未完成事项；有多个项目时先确认是哪一个 | 可继续使用的项目目录和进度记录 |

工作流记录 S0 至 S8 的研究阶段。你不必记住编号，也不必从头走一遍；已有材料会决定起点。重要的研究方向和结论范围仍由你确认。没有课堂数据时，可以讨论文献分析或教学设计路线，不能补造学生数据。

## 第一次使用，先做这几步

你需要能读写本地文件的 Codex，以及 Python 3.11 或更高版本。这里验证的是 Windows 环境；其他系统还没有同等安装验收记录。联网检索取决于当前 Codex 是否有搜索工具和来源访问权限。

源码、文档和发布附件已公开。可以直接在浏览器下载，也可以把本页地址交给能联网的 agent，无需为读取公开文件提供 GitHub 凭据。

如果你不熟悉安装，可以把下面这段话连同本发布页地址交给 Codex：

```text
请帮我安装并检查 cyz-edu-research 0.3.0。
发布页：https://github.com/chengyingzh433-stack/cyz-edu-research/releases/tag/0.3.0
先读取仓库 main 分支的 docs/agent-install.md，按其中的步骤执行。
从公开发布页下载并校验 ZIP，再安装到当前环境实际使用的 Skill 目录。
已有安装先检查并备份；发现本地修改时保留文件，不要自行强制覆盖。
安装后在临时项目中运行初始化和验证，分别报告主工作流、中文润色、英文润色、PDF 解析是否可用。
读取安装目录的 SKILL.md 和所需参考文件，再教我如何开始第一个研究项目。
不要把“Skill 安装成功”当作所有可选依赖都已可用。
```

[agent 安装与使用指南](https://github.com/chengyingzh433-stack/cyz-edu-research/blob/main/docs/agent-install.md)包含命令、检查项和失败时的处理方式。

## 自己安装

1. 在本页 Assets 中下载 `cyz-edu-research-0.3.0.zip`、`SHA256SUMS.txt` 和 `acceptance-report.md`。
2. 同时下载 GitHub 提供的 `Source code (zip)` 并解压。安装器位于源码中的 `scripts/install_skill.py`，不在 Skill ZIP 内。
3. 在解压后的源码目录新建 `dist` 文件夹，把第 1 步的三个文件放进去。在该源码目录打开 PowerShell。
4. 执行下面的校验和安装命令。示例使用当前用户的 `.codex/skills`；如果你的 Codex 使用其他位置，应改成实际目录。

```powershell
py -3.11 scripts/verify_release.py --dist dist
if ($LASTEXITCODE -ne 0) { throw '发布包校验失败，停止安装' }

$skillRoot = Join-Path $env:USERPROFILE '.codex/skills'
py -3.11 scripts/install_skill.py install --archive dist/cyz-edu-research-0.3.0.zip --skill-root $skillRoot
if ($LASTEXITCODE -ne 0) { throw '安装未完成，请先查看错误或冲突提示' }

$skillDir = Join-Path $skillRoot 'cyz-edu-research'
$checkProject = Join-Path $env:TEMP ('cyz-check-' + [guid]::NewGuid().ToString('N'))
py -3.11 "$skillDir/scripts/init_project.py" $checkProject --entry-mode discovery
if ($LASTEXITCODE -ne 0) { throw '测试项目初始化失败' }
py -3.11 "$skillDir/scripts/validate_project.py" $checkProject
if ($LASTEXITCODE -ne 0) { throw '测试项目验证失败' }
```

安装成功后，`cyz-edu-research` 目录里应直接有 `SKILL.md`、`VERSION`、`references`、`templates` 和 `scripts`。不要多套一层同名文件夹。回到 Codex 后新开一个对话；如果仍未识别技能，重启 Codex 再检查安装位置。

更新旧安装时，安装器会先备份。出现 `conflict` 表示检测到了本地修改或没有可用的旧安装记录，原安装不会被替换。先查看差异，再决定如何处理。[安装、升级与回滚说明](https://github.com/chengyingzh433-stack/cyz-edu-research/blob/main/docs/install-upgrade-rollback.md)列出了恢复命令。

## 安装后可以这样说

没有选题：

```text
$cyz-edu-research
我想做高中物理教学研究，目前没有选题，也没有可用的课堂数据。
请先帮我找适合现有条件的方向，每次只问我一个关键问题。
项目放在我当前工作区的“物理教学研究”文件夹。
```

有一个教学困惑：

```text
$cyz-edu-research
我发现学生能套用公式，但说不清公式为什么适用。
请从这个想法出发，帮我把研究问题问清楚，并查找相近研究。
```

已经有论文或稿件：

```text
$cyz-edu-research
我已经把材料放进当前项目。请先盘点已有成果和证据，告诉我最先缺哪一步。
保留我的原文件，未经核实的引文请明确标出来。
```

下次继续时，告诉 Codex 项目目录，再说“继续这个项目，先读取 00-项目状态.md”。项目中还会保存选题记录、文献卡、证据矩阵和稿件，换一个对话也能据此继续。

## 哪些依赖需要另装

主 ZIP 只包含 `cyz-edu-research`。下载这个文件不会自动安装所有相关工具。

| 功能 | 额外条件 |
| --- | --- |
| 选题、研究引导、项目记录 | Codex 与 Python；实时文献检索还需要可用的搜索能力 |
| 中文学术润色 | `humanizer-zh`，来源为 [syw2039/humanizer-zh](https://github.com/syw2039/humanizer-zh) |
| 英文学术润色 | `humanizer`，来源为 [blader/humanizer](https://github.com/blader/humanizer)，本轮验证版本为 2.9.1 |
| 本地 MinerU 解析 | MinerU Desk、本地模型及兼容的 `mineru` Skill；本轮实测为 Desk 0.3.1、MinerU 3.4.5、本地 Pipeline、离线模式 |
| 原生 PDF 提取回退 | 可用的 PyMuPDF；复杂表格、公式或扫描页需要另外核查 |

MinerU 包装 Skill 的再分发许可尚未确认，本发布不附带它，也没有通用的一键安装承诺。缺少某个依赖时，应报告缺失或采用文档允许的回退，不能声称对应功能已经验证。

**0.3.0 的语言检查有一项已知限制：** 发布包内的精简依赖清单缺少严格校验需要的字段，脚本默认查找锁文件的位置也不适合解压后的单 Skill 布局。请使用随本页补充提供的 `dependencies.verified-0.3.0.json`，并通过 `--dependency-lock` 明确传入路径。具体命令见 [agent 指南中的语言检查](https://github.com/chengyingzh433-stack/cyz-edu-research/blob/main/docs/agent-install.md#4-语言依赖与-030-兼容处理)。这份清单只认可本轮验证过的依赖内容；从上游下载的不同版本可能不匹配，不能通过删掉校验来宣称通过。
