# CYZ Workflow 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task, test-driven-development for every behavior change, and writing-skills for the skill-document pressure scenarios.

**Goal:** Deliver and publish a portable CYZ education-research skill version that adds evidence-bounded idea discovery/refinement, schema-2 lifecycle tooling, verified humanizer/MinerU integration, reversible installation, and WF01-WF12/REL01-REL03 evidence.

**Architecture:** The repository owns one standard skill package under `skills/cyz-edu-research`, stable machine contracts under `contracts`, deterministic Python lifecycle/release tooling under `scripts`, and unittest/scenario evidence under `tests`. Project Markdown remains authoritative; migration edits only stable managed regions and records hashes. Runtime dependencies remain sibling skills and local MinerU Desk components, pinned by hash in `dependencies.lock.json`; the release does not copy dependencies whose redistribution permission is unknown.

**Tech Stack:** Python 3.11+ standard library, Markdown/YAML-compatible frontmatter, JSON contracts, `unittest`, PowerShell installation verification, Git/GitHub Release.

**Execution prerequisite:** Configure truthful repository-local Git `user.name` and `user.email`. Do not invent an author identity. Keep all work on `feat/workflow-0.3.0`; do not add or push a remote until the target repository has been verified.
