# `cyz-edu-research` 现有 Skill 复用评估（v0.2）

## v0.2：学术语言打磨

- 从 MIT 许可的 `qu-ai-wei` 中吸收语体识别、密度判断、事实保护、过度改写防护、中文语序和节奏检查及打磨报告机制。
- 将通用“去 AI 味”改造成学术专用子流程，不强行加入私人经历、情绪或所谓“毛边”。
- 在 S7 实质内容定稿后执行，并在 S8 前增加确定性语义锁和人工语义回归。
- 工作台实际起草或重写简体中文论文正文时默认执行；允许记录 `不适用` 或 `用户跳过`，真人原稿和来源不确定文本默认先诊断。
- 新增 `scripts/check_semantic_lock.py`，检查改写前后的数字、统计表达、引文、DOI、图表编号、研究问题编号、占位符等高风险锚点。
- S8 后的任何正文改动都会使既有语言审查失效；导出前必须通过主稿 SHA-256 锁定。
- 明确该流程提升语言自然度和作者声音，不承诺规避 AI 检测，也不替代 AI 使用披露。

## 1. 评估结论

现有 Skill 库已经覆盖文献检索、全文读取、原文定位、文献矩阵、研究缺口、研究设计、论文写作和审查等多数底层能力。`cyz-edu-research` 不需要从零重写这些通用方法，但不能把现有 Skill 原样拼接起来。

最合适的路线是：

1. 吸收已有流程中经过验证的步骤、输出字段和质量关卡；
2. 改写为 `cyz-edu-research` 内部模块，不要求用户单独调用；
3. 删除自然科学、生物医学、Nature 投稿和多代理运行中的不适用规则；
4. 加入物理教学与教育学研究的对象、情境、方法、伦理和证据评价规则；
5. 增加现有 Skill 普遍缺少的“初学者导读、重点解释和阶段教学”；
6. 对可直接改编的第三方内容保留来源、许可证和修改说明。

## 2. 高价值复用来源

| 现有 Skill | 可吸收能力 | 需要改造之处 | 处理结论 |
| --- | --- | --- | --- |
| `grill-me` / `grilling` | 一次只问一个决策问题；给出推荐答案；先查事实再问判断；按依赖顺序逐项达成共识 | 原始定位强调持续压力测试，直接用于初学者可能过于强硬，也不适合机械任务 | 改造成温和的 `guided-mentor`，只在关键学术决策和阶段关卡启动 |
| `nature-reader` | 全文 source map；稳定文本块编号；页码、章节、图表定位；不确定内容显式标记；后续问答回到原文 | 默认要求完整中英对照，中文论文没有必要；输出偏“全文阅读器”，缺少教育研究质量评价和选题启发 | 吸收原文定位机制，改造成中文优先的三级精读 |
| `office-academic-skill` | 快速总览、阅读路线、关键图表、贡献、局限、与用户课题关系、原文依据索引 | 模板偏工程论文，强调模型、仿真、硬件和公式；默认面向 Word/PPT | 吸收阅读报告结构，替换为教育研究对象、理论、抽样、工具、数据和伦理字段 |
| `academic-research-suite/deep-research` | 可复现检索；题目/摘要与全文两轮筛选；带注释文献表；来源核验；文献矩阵；共识/分歧/沉默分析；跨论文张力清单；`three-way-scan` 的轻量 `WHY / HOW / WHAT` 论文比较 | 体量大、角色多、默认 APA 和通用/生物医学证据层级；部分流程对初学者过重 | 将 `three-way-scan` 直接改造成 `idea-scout` 的扫描内核；其他部分选择性改写，不复制完整套件 |
| `refine-literature-question` | 把宽泛主题转化为机制、条件、过程、对比或争议问题；三锚点检查 | 主要面向综述问题，尚未覆盖课堂现实条件和数据可得性 | 并入 `question-builder`，增加教育情境与可行性检查 |
| `locate-review-research-gap` | 以“已有进展—卡点—切入口—价值”形成可辩护缺口；禁止把未检索误写成无人研究 | 缺少检索复核记录、教育研究情境和方法可行性判断 | 并入 `gap-finder`，增加定向复核与实施条件评价 |
| `literature-review` | 多来源检索、纳排标准、PRISMA 式记录、主题综合、引文核验和综述质量检查 | 明显偏生物医学/自然科学；强制 AI 图片、多库数量、影响因子、名校和高被引阈值不适合普通教育研究 | 仅吸收通用系统检索和可复现原则，舍弃领域偏置规则 |
| `paper-spine` | resume-first；项目状态；阶段关卡；来源清单、证据库、主张登记表；中断后续接 | 配置和产物过多，流程面向成熟作者；强制 Word、LaTeX 和完整投稿包不适合日常入门 | 吸收断点续接、阶段门和证据登记思想，建立更轻量项目档案 |
| `research-writing-skill` | 不虚构数据或引用；区分原文、用户确认、推断和建议；先搭论证再写正文；章节检查 | 默认示例偏理工科，方法与结果字段不完全适合教育研究 | 并入 `paper-writer`，由课程知识包覆盖教育研究章节规范 |
| `nature-reviewer` | 区分已支持、证据薄弱和无法判断；明确评审边界；禁止补造证据 | Nature 评价轴和“三位审稿人”结构不是教育论文精读所必需 | 只吸收证据边界和非虚构检查，用于终稿审查而非日常精读 |
| `pdf` | PDF 文本提取、OCR、页面渲染和视觉核对原则 | 主要处理文件和版式，本身不负责学术理解 | 改造成包内的“PDF→Markdown 转换缓存”前置层，由 `paper-reading` 自动调用；原 PDF 继续作为权威来源 |
| `cnki-search`、`gs-search`、`wos-search`、`ieee-search` | 中文和英文数据库检索入口、结构化结果 | 依赖网络、账号、浏览器或数据库可用性；不能保证在分享环境中始终运行 | 整合统一检索接口和记录格式，并提供不可用时的降级说明 |

## 3. 文献精读模块的复用组合

新的 `paper-reading` 不从单一 Skill 复制，而是组合四类成熟能力；其中无选题扫描优先采用 `three-way-scan`，方向确认后才切换到标准精读：

```text
PDF→Markdown 缓存与网页可靠提取
  ← pdf + nature-reader

原文位置与来源映射
  ← nature-reader + office-academic-skill

研究问题、方法、证据和局限提取
  ← office-academic-skill + deep-research

质量评价、横向综合和研究启发
  ← deep-research + 教育研究方法课程知识

初学者讲解与重点标记
  ← cyz-edu-research 新增能力
```

### 3.1 可直接采用的输出机制

- 每篇论文建立稳定文献编号；
- 关键判断附页码、章节、图、表或文本块位置；
- 原文结论、工作台推断和使用建议分开；
- 不可靠 OCR 或缺失全文标为低置信度；
- 读完单篇后更新项目的文献证据矩阵；
- 后续问答必须回到同一来源定位，而不是依赖模型记忆。

### 3.2 必须新增的教育研究字段

- 教育问题与研究情境；
- 学段、学科、学校和课堂环境；
- 理论框架及核心构念；
- 总体、样本、抽样和纳排标准；
- 量化、质性、混合、准实验、行动研究等设计类型；
- 干预、比较条件、教师效应和课堂实施一致性；
- 问卷、量表、访谈、观察、测验和学习过程数据；
- 信度、效度、观察者一致性或质性可信度；
- 数据分析与研究问题是否匹配；
- 伦理审批、知情同意、未成年人保护和隐私；
- 结论可以推广到哪里、不能推广到哪里；
- 对物理教学实践和后续选题的启发。

### 3.3 必须新增的初学者导读

现有 Skill 大多能“提取”和“评价”，但没有充分解决初学者“不知道为什么这是重点”的问题。因此每篇关键论文还要输出：

- 为什么现在读这篇；
- 一句话说明研究内容和主要发现；
- 研究过程的通俗解释；
- 最值得记住的三点及其理由；
- 一眼看不懂的术语解释；
- 证据支持到什么程度；
- 哪些结论不能推出；
- 它对候选选题有什么具体启发；
- 下一篇应该读什么类型的文献，以及原因。

## 4. 文献综合模块的复用组合

文献综合采用 `deep-research` 中较成熟的矩阵、跨论文比较和 `three-way-scan` 结果，但改造成适合教育研究的证据矩阵。

保留：

- 按主题组织而非逐篇罗列；
- 比较三篇及以上研究形成的共识；
- 识别结论方向相反或条件不同的研究；
- 从样本、学段、学科、情境、工具、干预和分析方法解释差异；
- 对未覆盖主题标记“候选空白”，而非直接认定研究缺口；
- 每个跨论文判断保留文献编号和证据位置。

改造：

- 不使用一套通用的 I—VII 证据等级压平所有教育研究；
- 不把定性研究、案例研究自动置于量化研究之下；
- 按研究问题和设计类型选择相应质量标准；
- 量化、质性和混合研究分别评价，再进行综合判断；
- 对课堂生态有效性、教师实施、学生差异和情境边界给予专门关注。

## 5. 明确不采用的规则

以下规则虽然出现在现有 Skill 中，但不应进入 `cyz-edu-research` 默认流程：

1. 每篇或每份综述都必须生成 AI 图片；
2. 仅凭引用次数决定文献质量；
3. 仅凭影响因子、名校或作者声誉判定证据可信度；
4. 默认认为 RCT 永远优于质性、案例或行动研究；
5. 所有英文论文都必须制作全文逐段中英对照；
6. 所有检索都强制使用固定数量的数据库；
7. 所有项目都强制生成 LaTeX、Word、PDF 和投稿包；
8. 为了显示流程完整而模拟多个审稿人或代理角色；
9. 因暂时没有搜索到文献，就宣称该领域没有研究；
10. 用摘要级信息支持需要全文方法或结果才能确认的结论。

## 6. 授权与分享边界

本地 `academic-research-suite/ars` 明确采用 CC BY-NC 4.0。若直接改编其受版权保护的表达、模板或文件，分享时必须：

- 保留作者和许可证归属；
- 标明进行了修改；
- 仅用于非商业目的；
- 不增加妨碍下游遵守该许可证的限制。

`nature-reader`、`office-academic-skill`、`paper-spine`、`research-writing-skill` 等顶层目录没有发现独立许可证文件。因此分享版不应逐字复制其 Skill 文本或整包文件，而应依据通用研究方法重新表述流程，并在来源清单中说明设计参考。

`office-academic-skill` 还明确说明其参考过一个 proprietary 的外部 PPT 项目，相关专有文本不得进入新包。

最终包应提供：

- `THIRD_PARTY_NOTICES.md`：列出参考或改编来源；
- `licenses/`：保存允许再分发内容的许可证；
- `改造说明.md`：说明吸收了哪些思想、删除了哪些领域偏置、增加了哪些教育研究规则；
- 新包自身的许可证，并明确第三方部分仍受各自许可证约束。

## 7. 第一版的实现取舍

第一版优先整合以下能力：

1. 基于 `grill-me` 改造的单问题引导和决策记录；
2. 项目初始化、状态保存和断点续接；
3. 无选题时基于 `three-way-scan` 批量提取研究方向、问题、方法、对象和情境的粗粒度领域扫描；
4. 可复现的中英文检索和两轮筛选；
5. 方向确定后再执行快速筛选、标准精读和全文深读；
6. 初学者导读卡与重点标记；
7. 教育研究文献证据矩阵；
8. 共识、分歧、条件差异和候选缺口分析；
9. 研究问题—证据—方法对齐；
10. 论文分章节写作与证据状态管理；
11. 最终完整性审查。

后续版本再增加自动 DOI 核验、参考文献管理软件同步、复杂统计、系统综述专用偏倚工具和 Office/PDF/PPT 高级输出。
